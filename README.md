A deterministic Python-stdlib renderer that paints a 1024×1024 dusk travel poster for Luminara, an island that isn't there — a lighthouse on a dark cliff whose beam sweeps up into the stars, a low golden sun over a mirror sea, paper lanterns drifting up from the water, and one small sailboat heading home. The only copy on the poster is the place's name, set large across the sky, with one short line beneath it. No network, no system randomness: every star, lantern and wave comes from a fixed-seed generator, so two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, under 1 MiB). Pass a path as the first argument to write elsewhere, e.g. `python3 main.py entry.png`.
